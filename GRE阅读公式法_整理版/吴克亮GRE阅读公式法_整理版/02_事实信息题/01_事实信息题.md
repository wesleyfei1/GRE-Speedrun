# 事实信息题

> 整理来源：5.9 事实信息题录播；5.11 推断题；主旨题录播；第三次直播 信息目的 主旨目的；态度题 类比题 否定事实信息题。

事实信息题

| 题干标志 | **According to the passage**, ...?<br>                    or<br>**This passage mentions/states** which of the following as ...?<br>                   or<br>**Based  on  the passage,** ...? |
| --- | --- |
| 考点 | 定位 + 同义替换 |
| 正确答案 | 原文定位句的同义替换 |
| 错误答案特征 | 无中生有<br>非答案区间<br>逻辑错误<br>扩大或缩小范围 |


GRE 阅读错误选项特征
1. 无中生有 【文章中根本没有提】   ！！！！尤其是选项中的**比较关系中无中生有  90%**都有可能是错误选项  比较关系(同级  比较级  最高级)
2. 非答案区间   某些细节题 只与文章中几句话有关 这就是答案区间 其他区域则为非答案区间
3. 逻辑错误       即与原文矛盾  ！！！！ 尤其注意 选项中的**因果关系  90%都**是错的 比如 result in  lead to  /  as a result of 
4. 扩大或缩小范围    比如  原文 A+ B -> C 选项说 A -> C 这就是缩小范围 only
