# 吴克亮 GRE 阅读公式法｜整理版

这份目录由原始有道云导出 ZIP 去重、纠正格式并按题型重新整理得到。

## 推荐使用顺序

1. `00_通用方法`：先掌握题型导向、定位、同义替换和 GRE 常见错误选项。
2. `01_主旨题` ～ `09_长文章`：按题型学习公式。
3. `10_课堂例题与训练记录`：回看课堂例题、作业、练习和错题。
4. `11_资料`：保留原导出中的阅读 365 高频题号资料。

## 本次整理做了什么

- 删除整套重复的 `阅读(1)` 目录，只保留一份有效内容。
- 删除有道云自带的“在云笔记……”示例笔记。
- 删除 0 字节的 `无标题笔记.md`、`第三次直播.md`。
- 根目录重复的 `5.9 事实信息题录播.md` 与阅读目录版本合并为一份。
- 把原来混在一篇里的“态度题 / 类比题 / 否定事实信息题”拆开归类。
- 把“第三次直播 信息目的 主旨目的”中的内容按主旨题、句子作用题、信息目的题、事实信息题分别归档。
- 把“句子作用题”开头的通用定位规则单独整理进 `00_通用方法`。
- 把错误扩展名的 `阅读365高频题号.md` 识别为 PDF，并改为 `.pdf`。
- 保留课堂题目、作业、做题练习、自己练习、错题记录，不丢训练轨迹。
- 图片统一放在根目录 `assets/`，Markdown 内图片路径已重新连接。

> 注：整理主要针对结构、去重与归类；原笔记中的观点、公式、个人批注和题目分析尽量原样保留，没有替你重新校正其正确性。
