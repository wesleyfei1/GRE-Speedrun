# GRE 阅读错误选项四类

> 整理来源：5.9 事实信息题录播；5.8 短文章主旨题第一节笔记。

GRE 阅读错误选项特征
1. 无中生有 【文章中根本没有提】   ！！！！尤其是选项中的**比较关系中无中生有  90%**都有可能是错误选项  比较关系(同级  比较级  最高级)
2. 非答案区间   某些细节题 只与文章中几句话有关 这就是答案区间 其他区域则为非答案区间
3. 逻辑错误       即与原文矛盾  ！！！！ 尤其注意 选项中的**因果关系  90%都**是错的 比如 result in  lead to  /  as a result of 
4. 扩大或缩小范围    比如  原文 A+ B -> C 选项说 A -> C 这就是缩小范围 only
